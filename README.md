## ⚡ The Goood Way

### THE OLD WAY

Goood 是我的个人工作室入口。
想法很多，但结构很散。  
文档很厚，但判断不清。  
AI 生成很多内容，但不知道哪些真的有用。  
原型很漂亮，但没有帮助团队更快做决定。

它不是一份简历，也不是一个项目列表。它更像一张正在生长的工作台：我在这里整理产品判断、AI 应用、体验设计和原型落地的方法，把脑子里的想法变成更清楚、更好讨论、更容易验证的东西。
### THE GOOOD WAY

我喜欢做的事，是把混乱的信息压成结构，把抽象的判断变成流程，把还说不清的产品方向做成能被看见、能被点击、能被继续迭代的版本。
先看见问题，再整理结构。  
先形成判断，再进入方案。  
先做出可以被讨论的版本，再通过反馈继续迭代。  
让 AI 参与生成、整理、推荐和检查，但关键判断始终回到人。
